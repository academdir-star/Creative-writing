# Мастерская письма Skill Matrix

Интерактивный курс creative writing для школьников 13–18 лет. Ученик пишет с первой минуты:
короткий урок → один приём → пример «до/после» → упражнение прямо на сайте → обратная связь и
переписывание фрагмента → рефлексия. Интерфейс и все упражнения — на русском и английском.

- **Карта курса и учебные принципы:** [`docs/course-map.md`](docs/course-map.md)
- **Как устроен контент и как добавлять уроки:** [`docs/content-spec.md`](docs/content-spec.md)
- **Правила для будущего AI-помощника:** [`docs/assistant-guardrails.md`](docs/assistant-guardrails.md)
- **Прежняя страница курса (лендинг для записи):** [`landing/`](landing/index.html)

## Как открыть

Сайт статический, сборка не нужна. Работает и с диска (двойной щелчок по `index.html`), и с сервера:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

Один файл для показа (всё внутри, открывается где угодно):

```bash
python3 tools/bundle.py            # → dist/writing-studio.html
```

## Что внутри

| Экран | Что делает |
| --- | --- |
| Главная | Задание на 5 минут прямо на странице, «Продолжить» последний черновик, текущий маршрут, вызов недели, прогресс, фраза из коллекции |
| Маршруты | Основа (3 урока) и 6 маршрутов: Пишу свободно, Язык и стиль, Истории и персонажи, Реальный мир, Конкурсы эссе, Поступление и стипендии. У каждого — последовательность уроков и конкретный итог |
| Урок | Зацепка → приём → пример «до/после» с подсветкой разницы → упражнение → «Улучши» → рефлексия, самопроверка, вопрос для обсуждения, перенос в другие жанры, более сложный вариант, подсказка «не знаю, с чего начать», альтернатива без личного |
| Редактор упражнения | 11 механик: свободное письмо с таймером, список, переписывание, письмо с ограничениями (проверка вживую), колонки, шаблон, выбор с разбором, перестановка фрагментов, разметка текста, сравнение версий, генератор карточек. Автосохранение, история версий, режим фокуса, коллекция фраз |
| Лаборатория стиля | 12 приёмов: пример, песочница с живым «счётчиком» (ритм, прилагательные, чувства, клише, точка зрения…), когда помогает / мешает, неудачная попытка, перенос на свой текст |
| Библиотека | Аналитическое чтение (разметка текста тегами, заметки редактора, вопросы, попытка приёма) и сравнение двух версий с тремя вопросами |
| Мастерская эссе | Проекты: разбор задания → личный материал (ценности, чувства и потребности) → идея → структура → черновик → обратная связь → редактура → проверка фактов и лимита. Помощник задаёт вопросы и предлагает редакторские решения, но не пишет за ученика |
| Тематические мастерские | 12 тем: свадьба, побег, родственник, милый персонаж, лицо, слипстрим, юмор, абсурд, фантастика, эмпатия, усталость, музыкальные приёмы |
| Словарь | Журнал слов, упражнения (оттенки, глаголы, контекст, регистры, сочетаемость…), автоматический подсчёт «активированных» слов по собственным текстам ученика, график по неделям |
| Портфолио | Все черновики, готовые тексты, коллекция фраз, прогресс по навыкам (без баллов и серий), экспорт |
| Преподавателю | Принципы, сценарий занятия, протокол обратной связи, безопасность, заметки к каждому уроку, источники |

## Как устроен код

```
index.html            оболочка приложения
css/app.css           стили (светлая и тёмная тема)
js/core/              утилиты, переводы интерфейса, хранилище, анализ текста, обратная связь
js/ui/                общие элементы, редактор упражнений, история версий
js/views/             экраны
js/content-api.js     реестр контента
content/*.js          весь учебный контент (RU + EN)
tools/                проверки и сборка
landing/              прежняя страница курса
```

Проверки:

```bash
node tools/validate-content.js   # схема контента, оба языка, лимиты длины
node tools/check-strings.js      # все строки интерфейса есть на обоих языках
```

## Что работает локально, а что требует сервера

| Функция | Сейчас | Для полной версии |
| --- | --- | --- |
| Черновики, версии, портфолио, прогресс | В браузере (localStorage) + скачивание и загрузка резервной копии в «Настройках» | Аккаунты и серверное хранилище |
| Обратная связь по тексту | Локальный анализ поверхности текста: слова-чувства, ярлыки, клише, повторы, ритм, лимит. Честно предупреждает, что не понимает смысла и для русского точен хуже, чем для английского | AI-сервис по правилам из `docs/assistant-guardrails.md` + выборочная проверка преподавателем |
| Помощник в мастерской эссе | Вопросы по этапам и по сигналам черновика, меню редакторских решений | AI-сервис с теми же ограничениями |
| Обмен работами и комментарии | Добровольный экспорт текста; взаимный отзыв на одном устройстве | Сервер с модерацией, согласием родителей, без публичных профилей |

## Источники

Все упражнения и примеры написаны для курса; тексты книг и чужие эссе на сайт не копировались.
Что вдохновило каждое упражнение, указано в разделе «Преподавателю» и в поле `teacher.source` урока.
Сайты 826 Digital, OpenLearn, Purdue OWL, Writing Excuses и Young Writers были недоступны из среды
разработки: сведения о них собраны по поисковым выдержкам и перед цитированием требуют проверки.
