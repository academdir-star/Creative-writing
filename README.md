# Creative Writing — Skill Matrix

Одностраничный сайт курса творческого письма для школьников (Алматы).
Язык сайта — английский. Статический сайт без сборки: HTML, CSS и немного JavaScript.

```
index.html          — вся страница
css/styles.css      — стили
js/main.js          — меню, анимации, мобильная кнопка записи, форма
assets/favicon.svg  — иконка вкладки
```

## Как посмотреть

Откройте `index.html` в браузере или запустите любой локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Разделы страницы

1. **Hero** — заголовок, описание курса, кнопки «Sign up» и «Learn about the course».
2. **Who it's for** (`#for-whom`) — для кого курс и короткое обращение к родителям.
3. **What students learn** (`#skills`) — шесть навыков: идея, сюжет, персонажи, язык и стиль, редактирование, обсуждение.
4. **How classes work** (`#format`) — практический формат: упражнения, свои тексты, обсуждение, поддержка преподавателя.
5. **Student work** (`#works`) — места для отрывков из работ учеников.
6. **Programme and schedule** (`#program`) — карточки для заполнения.
7. **FAQ** (`#faq`) — частые вопросы.
8. **Request form** (`#apply`) — заявка на консультацию или пробное занятие.

## Что заполнить перед запуском

Все места, где не хватает данных, помечены в `index.html` комментариями `TODO`,
а на странице показаны как `to be announced`. Найти их можно так:

```bash
grep -n "TODO\|class=\"tbd\"" index.html
```

| Что | Где | Как заполнить |
| --- | --- | --- |
| Возраст, уровень английского, язык обучения, продолжительность, дни занятий, стоимость | `#program` | Замените `<span class="tbd">to be announced</span>` на текст, например `<dd>12–16 years old</dd>` |
| Преподаватель | `#program`, карточка `fact--teacher` | Имя вместо `tbd`, пара предложений в `teacher__bio`; фото — замените `<span class="teacher__photo">…</span>` на `<img class="teacher__photo" src="…" alt="Имя преподавателя">` |
| Язык занятий и итоговый результат курса | `#faq`, вопросы 2 и 3 | Замените `tbd` на ответы |
| Работы учеников | `#works` | Замените карточку `work--placeholder` на шаблон из комментария над ними. Публикуйте только с согласия автора и родителей |
| Контакты | футер | Телефон / WhatsApp, адрес, Instagram |
| Обработчик формы | `#apply` | См. ниже |
| Политика конфиденциальности | под кнопкой формы | Добавьте ссылку, если политика есть |
| Логотип | шапка и футер | Замените значок и текст в `.brand` на официальный логотип, если нужно |
| `og:url`, `og:image` | `<head>` | После публикации — для красивого превью в мессенджерах |

## Форма заявки

Пока у тега `<form>` нет атрибута `action`, форма работает в **демо-режиме**:
проверяет поля и показывает сообщение «Thank you», но никуда не отправляет данные
(на экране успеха видна пометка «Demo mode»).

Чтобы заявки приходили, добавьте форме адрес обработчика:

```html
<form class="apply-form" action="https://formspree.io/f/ВАШ_ID" method="post" novalidate data-form>
```

Подойдёт любой сервис, который принимает `POST` с `FormData` и отвечает кодом 2xx:
Formspree, Getform, Google Apps Script (запись в Google Таблицу), вебхук CRM (amoCRM, Bitrix24) и т. п.

Поля, которые отправляет форма:

| Поле | Значение |
| --- | --- |
| `course` | `Creative Writing` |
| `interest` | `Consultation` или `Trial class` |
| `parent_name` | имя родителя |
| `student_age` | возраст ученика (6–18; границы задаются атрибутами `min`/`max` поля) |
| `phone` | телефон или WhatsApp |
| `contact_method` | `WhatsApp`, `Phone call` или `Telegram` |

Кнопки «Book a trial class» / «Sign up» автоматически выбирают в форме «Trial class»,
кнопки «Book a consultation» — «Consultation».

## Публикация

Сайт статический, его можно выложить на любой хостинг: GitHub Pages
(Settings → Pages → ветка и папка `/`), Netlify, Vercel, Cloudflare Pages
или обычный веб-сервер — достаточно скопировать файлы.

## Что учтено

- Адаптивная вёрстка от 320 px; на телефоне внизу появляется кнопка записи, когда первый экран прокручен.
- Доступность: семантическая разметка, пропуск к содержимому, подписи полей, сообщения об ошибках для скринридеров, видимый фокус.
- Анимации отключаются, если в системе включено «уменьшение движения».
- Без JavaScript страница полностью читается, а FAQ работает на нативных `<details>`.
